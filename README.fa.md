# DNS Profile Manager

برنامه‌ی کوچک ویندوزی برای تغییر سریع DNS. پروفایل‌های DNS دلخواهتان را ذخیره کنید، کارت شبکه را انتخاب کنید و با یک دکمه وصل یا قطع کنید.

## قابلیت‌ها
- ذخیره‌ی هر تعداد پروفایل DNS (نام + DNS اول + DNS دوم)
- افزودن، ویرایش و حذف پروفایل
- انتخاب کارت شبکه
- Connect / Disconnect با یک کلیک
- پاک شدن خودکار کش DNS بعد از هر تغییر

## نصب
1. از بخش [Releases](../../releases) فایل `DnsProfileManager-Installer.zip` را دانلود کنید.
2. ZIP را کامل Extract کنید.
3. روی `Install.bat` دابل‌کلیک کنید و UAC را تأیید کنید.

حذف: Settings > Apps > Installed apps > DNS Profile Manager

> چون فایل‌ها امضای دیجیتال ندارند، ممکن است SmartScreen هشدار بدهد: More info > Run anyway.
